# 컬러 스트룹 🎨

색 이름 글자가 **다른 색으로 칠해져** 나온다. 글자를 읽지 말고 **칠해진 색**을 고르는 반응·두뇌 게임(스트룹 효과). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 서버 없이 `index.html` + `logic.js` + `game.js` 만으로 돈다.

- **기본 규칙**: 가운데에 "초록" 같은 글자가 나온다. 글자가 말하는 색이 아니라 **글자에 칠해진 색**과 같은 버튼을 누른다. 글자와 색이 같은 쉬운 문제도 가끔(20%) 나온다
- **규칙 바뀜**: 12번째 문제부터 4문제 동안은 반대로 **글자 뜻**을 고른다("🔄 글자 뜻!"). 그 뒤 16문제 주기로 되풀이(`WORD_FROM`·`WORD_LEN`·`WORD_EVERY`)
- **색**: 처음 4가지, 8문제 뒤 5가지, 20문제 뒤 6가지(빨강·파랑·초록·노랑·보라·주황). 버튼에 숫자 1~6 이 붙어 있어 키보드로도 누른다
- **제한 시간**: 문제마다 처음 3.2초, 한 문제 풀 때마다 50ms 씩 줄어 1.2초까지(`START_MS`·`SHRINK_MS`·`FLOOR_MS`)
- **목숨**: ❤️ 3개. 틀리거나 시간이 지나면 하나를 잃고 콤보가 끊긴다. 다 잃으면 끝. 틀린 문제는 정답 버튼을 잠깐 보여 준다
- **점수**: 한 문제 10점 + 빨리 맞힐수록 최대 10점(남은 시간 비율), 거기에 **콤보 배수**(5개 이어서 맞힐 때마다 +1, 최대 x5). 최고 점수는 `stroopBest`(로비 표시용)
- 화면이 가려지면(탭 전환) 그 문제의 남은 시간을 멈췄다가 돌아오면 이어서 한다. 튜토리얼(`?tutorial=1`)에서는 시간이 사실상 무제한이고 목숨이 다 없어져도 끝나지 않는다

규칙은 `logic.js`(화면 없이 Node 로 시험), 화면·입력·소리는 `game.js`. 시험은 `node --test`(디렉터리): `test/logic.test.js`(색 6개, 색 개수 늘어남, 글자 뜻 규칙 주기, 제한 시간 줄어듦, 콤보 배수, 문제가 범위 안이고 정답이 규칙을 따름·글자와 색이 같은 비율, 점수와 속도 보너스, 콤보, 틀리면 목숨·콤보, 시간 초과를 따로 셈, 목숨 3개면 끝, 잘못된 입력 무시, 연습용 목숨, 완벽한 사람과 어설픈 사람 시뮬레이션).
